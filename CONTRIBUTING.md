# Участие в TgBotSmoke

Репозиторий приватный; правила предназначены для участников с доступом.
Для изменения создайте отдельную ветку и pull request с описанием поведения
до и после, причины изменения и выполненных проверок.

## Разработка

Настройте окружение по [README](README.md#локальная-разработка).
Используйте отдельного тестового бота и локальную D1. Не запускайте polling
с токеном рабочего бота и не меняйте production webhook для проверки кода.

- Сохраняйте хронологию серий, достижения, точность Decimal и защиту от дублей.
- Для изменений поведения добавляйте короткие регрессионные тесты.
- Медицинские утверждения сопровождайте проверяемыми первичными источниками;
  не превращайте статистические оценки в личные обещания.
- Тексты и этапы экспортируются из Python в `cloudflare/src/assets.json` через
  `cloudflare/scripts/export_assets.py`. Обновляйте исходник и экспорт вместе.

## Проверки

Из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
npm test --prefix cloudflare
git diff --check
```

Для правок только документации достаточно сверить её с кодом, проверить ссылки,
примеры команд и состав diff. Не развёртывайте Worker ради правок документации.

## Секреты и данные

Не прикладывайте токены, `.env`, `.dev.vars`, содержимое диалогов, базы или резервные
копии к коммитам, issue и логам. Для примеров используйте вымышленные данные.
О возможной утечке сообщайте владельцу репозитория приватно, без публикации секрета.
